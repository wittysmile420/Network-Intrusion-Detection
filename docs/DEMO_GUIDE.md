# 10–15 minute demo

1. Start `python run.py` (2 min).
2. Open the dashboard and health endpoint (1 min).
3. Generate normal loopback traffic (2 min).
4. Explain TCP/UDP/ICMP header fields (2 min).
5. Run abnormal mode with a lowered threshold in `.env` if desired (2 min).
6. Acknowledge and resolve an alert (1 min).
7. Generate CSV/JSON reports (1 min).
8. Parse fallback traces or run NS2 (2 min).

Expected output is a packet count, protocol breakdown, alert rows, and downloadable reports. Stop with Ctrl+C. This demo is loopback-only and non-disruptive.
