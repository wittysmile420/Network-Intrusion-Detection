# Installation

Windows, Linux, and macOS use the same Python commands. Windows live capture requires Npcap and administrator permission where the selected interface requires it; Linux may require `sudo` or capture capabilities. Install optional Scapy with `pip install -e ".[capture]"`. TShark is optional and is not required for replay/demo mode. NS2 is optional; use the checked-in sample traces when `ns` is unavailable.
