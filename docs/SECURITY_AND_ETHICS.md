# Security and ethics

Use SNIDS only on interfaces and networks you own or have explicit permission to monitor. It stores header-level fields only and never stores raw payloads. It has no attack, exploitation, packet injection, blocking, or disruption feature. Demo traffic is loopback-only, rate-limited, and synthetic. Do not point it at public or unauthorized hosts. Reports may contain IP addresses; protect generated files and delete them when no longer needed.
