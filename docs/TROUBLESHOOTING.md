# Troubleshooting

Use demo mode when capture permissions, Npcap, or TShark are unavailable. Delete only a disposable `data/snids.db` if a classroom database is corrupted. Change `SNIDS_PORT` if Flask is busy. Keep reports on a local trusted folder. If charts do not appear, use the data cards and API endpoints; the current dashboard has no external chart dependency. NS2 is optional; sample traces are the validated fallback.
